# Contributing

Read this repository's `README.md`, `AGENTS.md` (if present) and the [Vulcis engineering conventions](https://github.com/vulcis/vulcis/blob/develop/docs/ENGINEERING_STANDARD.md).

Use `develop` as the pre-production integration branch. Create a short issue branch, write English Conventional Commits and PR titles, and integrate via Squash and merge. Write the issue explanation and acceptance criteria in Portuguese when useful. Review the PR technically; human acceptance is normally at release level, except high-risk changes.

Preserve existing work, assets and history. Use worktrees only for actual concurrent work; follow repository-specific build and test instructions.
